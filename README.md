1. Setup
  a. Make sure you hava Java 17 setup including IDE.
  b. Clone 3 services Client Bank A, Client Bank B and Bank Server.
  c. Do Maven update to all services.

2. Run
   a. To run you can directly run on IDE, or you can to "mvn clean install" to create a jar file of it and run it.

3. Test
   a. Follow the instructions given in database folder file of the github repo and run that query, to setup the data.
   b. You can use any testing tool like PostMan, SoapUI, etc
   c. APIs and sample JSON are given in requests folder of this github repo.
